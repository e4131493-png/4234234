Dropzone Optimizer is a local Windows app with reversible Fortnite video presets, optional Windows performance settings, and a low-input-latency checklist.

Configured for an i5-10600K, RX 6600, 16 GB RAM, and a 1080p / 280 Hz monitor. It includes adjustable frame caps (including 277, 280, and unlimited), rendering scale, and backup/restore.

### Download and run

1. Download **Dropzone-Optimizer-1.0.0-Windows-x64.zip** from the assets below.
2. Right-click the ZIP and choose **Extract All**. Keep all the extracted files together.
3. Open **Dropzone Optimizer.exe**.
4. Close Fortnite, select **Competitive**, and review the proposed changes before applying them.
5. Use **Backup & restore** to recover your previous settings.

This is an unsigned Windows x64 build. FPS improvements and input latency have not been measured on your PC. Rendering mode and AMD driver settings are guided manual steps. The 280 FPS figure is a display target, not a guaranteed result.
